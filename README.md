# ⌨️ MedaBinds

**Keybind overlays for Blizzard's Cooldown Viewers.** See your bindings at a glance.

![WoW](https://img.shields.io/badge/WoW-12.0%2B-orange) ![License](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ Features

- 🔍 **Auto-detect** keybinds from all action bars, macros & Bartender4
- 🎯 **Multi-viewer** support (Essential, Utility, Buff icons & bars)
- 🔗 **External tracking** - attach overlays to any addon's icons
- 🎨 **Fully customizable** fonts, colors, positioning & per-spell overrides
- ⚡ **Smart abbreviations** (`SHIFT-CTRL-5` → `SC5`)

---

## 🚀 Quick Start

```
/mbinds        → Open settings
/mbinds config → Toggle config mode (ALT+click icons to customize)
/mbinds scan   → Force keybind rescan
```

## 📦 Install

Download from [CurseForge](https://www.curseforge.com/wow/addons/medabinds) • [Wago](https://addons.wago.io/addons/medabinds) • [GitHub Releases](https://github.com/Medalink/MedaBinds/releases)

Extract to `World of Warcraft/_retail_/Interface/AddOns/` → `/reload`
